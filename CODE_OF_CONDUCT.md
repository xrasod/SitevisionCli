# Code of Conduct

This project is maintained by one person in their spare time. These are the
ground rules for issues, pull requests and discussions here.

## Be decent

- Be respectful and constructive. Disagree with ideas, not with people.
- Assume good intent. Most confusion is a missing detail, not malice.
- Give feedback the way you would want to receive it: specific, about the
  code or the problem, and without sarcasm.
- Keep it professional. No harassment, personal attacks, discriminatory
  remarks or sexualized language, in public threads or in private messages
  related to this project.
- Do not post other people's private information, and keep site URLs,
  usernames and credentials out of issues and PRs.

## Be useful

- Search before opening an issue, and use the issue forms.
- Stay on topic. Questions about the Sitevision platform itself belong at
  [developer.sitevision.se](https://developer.sitevision.se).
- Do not bump issues or ping for updates. Responses come when there is time.
- A closed issue or declined PR is not a judgement of you. If you think the
  call was wrong, say why once, calmly.

## Enforcement

Comments that break these rules will be edited or removed, and repeat
offenders will be blocked from the repository. If something is directed at
you and you would rather not raise it publicly, message the maintainer,
[@xrasod](https://github.com/xrasod), on GitHub.
